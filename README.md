# Everest Chronicle Next.js Build Prompts

This package contains step-by-step `.md` prompts for recreating the Everest Chronicle Figma homepage in a clean Next.js + TypeScript + Tailwind CSS v4 project.

## Usage

Run each prompt in order:

1. `docs/01-project-cleanup.md`
2. `docs/02-project-structure.md`
3. `docs/03-design-tokens.md`
4. `docs/04-typography.md`
5. `docs/05-layout-container-grid.md`
6. `docs/06-header.md`
7. `docs/07-home-hero.md`
8. `docs/08-featured-and-latest.md`
9. `docs/09-category-sections.md`
10. `docs/10-shorts-section.md`
11. `docs/11-newsletter.md`
12. `docs/12-footer.md`
13. `docs/13-responsive-homepage.md`
14. `docs/14-final-figma-refinement.md`

The prompts intentionally avoid large opinionated UI libraries so the implementation can match the Figma more closely. Small focused libraries can be added later when there is a clear need.
