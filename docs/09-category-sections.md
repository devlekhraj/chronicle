# Everest Chronicle — Step 09
# Category Sections

Build reusable category sections for:
- Expeditions
- Environment
- Conservation

## Component

Create a reusable `CategorySection` component that accepts:
- title
- articles
- optional href

## Desktop

Each section shows 3 article cards in a row.

Each article card contains:
- image
- category tags
- title
- excerpt
- date
- author

## Section Heading

Use a compact bold heading with a thin brand-green underline/accent matching the Figma.

## Article Card

Create a reusable `ArticleCard` with no heavy border/shadow.

The image area should be prominent, with text stacked below.

## Responsive

- desktop: 3 columns
- tablet: 2 columns where practical
- mobile: 1 column

Avoid horizontal squeezing that damages readability.
