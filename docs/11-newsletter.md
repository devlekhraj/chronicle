# Newsletter Section

Recreate the centered newsletter signup area above the footer.

## Content

Heading:
`Subscribe to our newsletter`

Input placeholder:
`Your email here`

Button:
`Subscribe`

Supporting line:
`Some kind of blurb about the newsletter, what you get`

## Visual Rules

- centered heading
- long email input with attached/adjacent compact button
- brand-tinted button background
- subtle border
- large surrounding whitespace
- no unnecessary card container

## Accessibility

- proper `<label>` (can be visually hidden)
- input type `email`
- button type `submit`

Do not implement backend submission yet.
